Current scope: one whole Ingredient, one existing Cook Action/Intent, one pinned pot and station, one specified supporting preparation Furniture. No authoring/schema or material transformation change.

- Exposed-input Cooking retains its original provider path and visual gate. Only if no such plan exists, the provider can consider a reachable fixed Object-containment Furniture from actual local contact or visual evidence, with a known legal support and visible cookware. A remote plan does not include a hidden ingredient ID or depend on remote storage contents; it is an uncertain inspection attempt. At current local contact an empty or unsuitable source is not a usable plan.
- Action construction revalidates current evidence and pinned IDs. `toStorage` reserves the source, preparation surface, pot and station. `inspectContainedObjects` at real contact provides child IDs; selection reuses existing Cooking eligibility over a pure hypothetical exposed placement, actual hand capacity, reservation, and existing generic take. `stageIngredient` uses the real carried state and current support contact geometry; invalid capacity, target or reservations abort rather than silently choosing another intended surface. - `releaseHeldObjectOnSupport` and ordinary nearby release share the same candidate selection and support mutation. On success `Object.supportId` and `position` refer to the actual support; no parallel inventory, carried state or placement mirror.
- `takeContainerCargo` cites an actual preceding transfer/acquisition when retained in the canonical event store; `objectSupportPlacement` cites extraction. The existing `cookMeal/pickupIngredient → loadPot → complete` chain cites the actual placement. No extra material mutation or duplicated World Event. Existing same-Action private phase/evidence is not a World truth.
- The real production regression covers source visibility/contact, local inspection, no hidden item claim, exact supported placement, held/contained identity, invalid target, capacity/reservation, interruption, same Intent, ordinary exposed Cooking and actual R3→R4-A1→R4-A2 event ancestry. Canonical Node and Browser gates remain required.

A remotely inspected empty source can lead to an abort, rather than invented ingredients; broader retry/search policy is deferred.
