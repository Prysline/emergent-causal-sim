# v7 架構說明

## 分層

### `world.js`
只描述「世界裡有什麼」：資源種類、中文名稱、區域拓樸、角色、容器、來源、表面與初始數值。

### `engine.js`
只處理「世界如何變化」：需求漂移、決策權重、多階段行動、移動、等待、物品持有、資源轉移、污染、攝入、醉酒、噪音與事件因果。它不應直接操作 DOM。

### `ui.js`
只處理「如何看見世界」：地圖、目前行動、摘要時間線、完整時間線、Inspector 與手機分頁。它透過 `SimEngine` 讀取狀態並觸發 tick/reset。

## UI 設計原則

1. 世界狀態優先於事件文字：先看地圖，再看 log。
2. 細緻行動不等於細碎畫面：目前行動用摘要卡，完整階段放到時間線完整模式。
3. 所有可識別 Entity 使用同一 Inspector 模式。
4. 容器名稱不決定用途。杯子是容器，不是酒專用物件。
5. Debug 因果保留完整，但不強迫預設畫面全部顯示。

## 下一步候選

- Engine 事件正式加入 `importance`、`actorId`、`entityIds`，取代 UI 文字推斷。
- 物品與資源加入更正式的 property schema，例如材質、重量、液體相容性、易燃性。
- 地圖加入行動路徑／移動中的視覺提示。
- 事件與物品加入「歷史變動」索引，快速追蹤內容物從哪裡來。
